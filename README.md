# Everything 5.75 — Full React Commerce Demo

A bilingual Arabic/English React storefront with light/dark mode, customer shopping flow, favorites, cart, checkout, order history, seller application flow, and a responsive admin dashboard.

## Run web app

```bash
npm install
npm run dev
```

## Demo admin

Open the app, go to Settings -> Dashboard, or set the hash to `#admin` before refresh.

## Production API mode

Copy `.env.example` to `.env`, set `VITE_API_MODE=api`, and set `VITE_API_BASE_URL` to your Laravel API URL. See `docs/BACKEND_SETUP.md`.
